# Product & lifestyle images

Upload each product photo into **this folder** using the **exact filename**
listed below. The app already references these paths in
`src/data/content.js`, so once a file is here it renders automatically. Until
then, a styled gradient placeholder is shown (nothing breaks).

> Easiest way to upload: on GitHub, open this folder →
> **Add file → Upload files** → drag the images in → **Commit**.
> Keep the filenames exactly as below (all lowercase, `.jpg`).

## Required filenames

## Recommended sizes
- Product shots: square, ~800×800px, `.jpg` or `.webp`
- Hero / lifestyle: landscape, ~1600×1000px

## Using a different filename or format?
Update the matching `image:` value in `src/data/content.js`. If you prefer
`.webp` or `.png`, just change the extension in both places so they match.

See the main `README.md` → "Adding real product / lifestyle images".
