# Product & lifestyle images

Drop image files here (e.g. `moringa-powder.jpg`) and reference them from
`src/data/content.js` with a root-relative path such as
`image: '/images/moringa-powder.jpg'`.

Recommended:
- Product shots: square, ~800×800px, `.jpg` or `.webp`
- Hero / lifestyle: landscape, ~1600×1000px

See the main `README.md` → "Adding real product / lifestyle images".
